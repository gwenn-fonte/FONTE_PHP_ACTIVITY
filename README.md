# PHP Include and Form Validation

Individual assignment: Code Organization with PHP Include and Form Validation Using Regular Expressions.

## Structure
```
index.php            main page (include statements only)
login.php            login form + PHP/regex validation
register.php         register form + PHP/regex validation
logout.php
style.css            styles for login/register
landing.css          styles for the landing page
includes/            head, header, nav, main-content, footer, auth, functions
data/users.json      registered users (passwords hashed)
images/              project images
screenshots/         code and output screenshots
```

## How to run
1. Put the folder in `C:\xampp\htdocs\`
2. Start Apache in XAMPP
3. Open `http://localhost/<folder-name>/login.php`
4. Test login: `admin` / `12345`, or register a new account
